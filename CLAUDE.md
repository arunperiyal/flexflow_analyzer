# CLAUDE.md

## Output

- **Never use Claude Artifacts** (no publishing pages to claude.ai). When a
  page, diagram or report is useful, write a standalone HTML file into the
  repository (e.g. `docs/auto_flow.html`) that opens in a local browser.
  Load any library it needs (e.g. Mermaid) from a CDN in the file itself.

## NEXT_SESSION.md

- Write or update `NEXT_SESSION.md` only when the user says so. Do not
  refresh it on your own at the end of a piece of work.
